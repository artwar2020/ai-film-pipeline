# 制作流程与提示词结构

这是从公开制作经验提炼并经本地调整的工作流程。模板字段按镜头需要选用，不要求每次填写全部栏目。

## 资产准备

资产记录建议包含：标识、版本、用途、完整描述、参考文件、状态、测试结果。用同一标识连接分镜、提示词和实际上传的参考图；不同状态单独管理。

角色参考应清楚呈现面部和服装轮廓。写实项目可采用中性背景、平实光照、大幅面部参考与身体正反面，避免在身份素材里固化特殊场景灯光。风格化项目按其视觉语言设计。保留原始资产，局部改动优先局部编辑，检查纹理与颜色损失。

声音描述记录音区、音色、语速、口音和表达习惯；行为描述记录步态、手部习惯、视线及压力反应。同一行为能量可随姿势换一种表现，不把站立动作硬塞进坐姿。

测试覆盖真正会用到的条件，例如侧脸、远景、低照度、运动、双人同框。少量代表性样片先验证可行性，再按预算增加覆盖；失败也可能来自参考图、参数或模型能力，不只来自描述。

## 场景和剪辑连续性

先建立固定场景坐标：地标、人物可活动区域、相对距离、主光方向与摄影轴线。再为各镜头写出机位以及该机位看到的画面左右。对白尽量使用足以表达关系的空间，不无谓扩大范围。

参考图分别说明只用于身份、服装、空间、构图、光色或首尾帧中的哪一项。作为首帧的图需要继承构图；作为空间参考的图不必强制继承构图，二者不能混淆。

每个镜头记录入点和出点：人物站位与视线、左右手持物、身体朝向、动作阶段、服装伤痕状态、情绪余波。反打不只是更换人脸，还要检查视线和空间轴线。

## 镜头结构

以下是内部编写结构，并非某个平台的 API 字段。提交时按工具能力组织成自然语言或实际字段。

```text
镜头标识与版本：
叙事目的：这条镜头让观众获得什么信息或看到什么变化
执行参数：时长、画幅、真实分辨率、单镜头或多镜头、音频设置
出镜主体：人物数量、身份和状态；必要的道具数量与归属
参考素材：实际文件或工具标识 + 每张图的用途
资产描述：展开本镜头相关角色、场景、道具的锁定文本
场景地图：地标、距离、摄影轴线、固定光源
首帧与机位：景别、高度、位置、人物站位与视线
动作时序：在明确时间范围内描述可见变化，保持动作容量合理
镜头运动与对焦：与人物动作相容；静止机位也可以
物理关系：重量、接触、惯性和道具交接
表演：目标、阻碍、隐藏意图、可见身体反应与策略变化
声音：逐人声音描述、准确对白、发声时机、环境声及音乐安排
风格：本项目的光色、质感和节奏约定
连续性终点：为下一镜头留下的位置、动作和声音状态
验收标准：能够从实际画面和声音判断的成功条件
```

准确对白集中放在声音部分；动作部分描述发声时机而不重复台词。内部意图清楚标为不发声。无需说话的人是否静默、环境声是否压低、是否允许配乐，按本项目明确约定。默认拟在后期统一配乐的项目，可先只生成对白和现场声；音乐短片或用户指定原生音轨则保留需求。

将抽象情绪转成少量清楚的动作。例如：“想问清真相，但怕对方离开；手指沿杯沿摩挲，听到答复后停住，吸气后才开口。”不要机械堆叠微表情。

## 镜头诊断与提示词编排

写最终提示词前，先只保留当前镜头：出镜主体、活动道具、参考素材、动作、时长、机位、空间地标、光线和声音。删除场号、上一镜头摘要、未出镜人物、旧标签以及“继续上一个镜头”这类依赖模型记忆的句子。当前镜头应当像一份封闭的拍摄单。

提示词通常按这个顺序组织：场景目的 → 当前参考 → 场景地图 → 首帧和站位 → 镜头模式 → 光学结果 → 摄影机 → 时间动作 → 物理 → 光线 → 声音 → 局部约束。关键的站位、视线和光线放在风格形容词之前；不要让诗意语言覆盖可执行信息。

参考素材有层级：角色参考控制身份、比例、服装和纹理；场景参考控制建筑、材质、地理和氛围；道具参考控制形状、尺度、材质、接触和状态。明确每张图“只取什么”。场景图默认只继承空间与材质，不自动继承它的构图；只有用户要求时才把它当首帧或构图参考。

如果人物需要从第一帧出现，直接写“第一可见帧已经包含所有必要人物，并且站在规定位置”，同时说明不要空镜或延迟出现。若用户确实要空镜，说明它的空间信息和时长，避免让模型自行添加无关的建立镜头。

## 光学与摄影机控制

镜头选择先服从内容：空间动作适合广角空间感，肖像和远距离观察适合压缩背景的长焦，细节特写单独作为插入节拍。一个动作段不要同时要求环境全貌、面部近景和微距细节；需要时用明确的内部切镜。

描述镜头的可见结果、物理距离和视角，而不是堆叠品牌、光圈或相机型号。示例：相机离人物 4–6 米、背景被压缩成柔和色块、人物眼睛清晰；或者相机靠近主体、环境延伸到画面边缘、直线保持笔直。多镜头中每个镜头单独锁定光学特征，除非有意改变，不让视场角在镜头内部漂移。

摄影机要写成操作：高度、站在哪一侧、与主体的距离、画面位置、运镜路径、对焦对象和手持的物理感。手持应表现为呼吸、重心变化和微小修正；不要用随机抖动代替手持。光线要明确主光源、方向、相机相对光源的位置、曝光优先级和允许的高光。

## 行为、物理和对白

把“悲伤、愤怒、震惊”改写成身体工作与意图：呼吸变浅、下颌收紧又释放、视线先到目标再带动头部、手上的工作在听见关键信息后停住。人物要有目标和阻碍，并在镜头内改变策略；一个镜头从头到尾只做同一反应，通常会显得平。

物体运动要有原因：重量、接触、摩擦、惯性、衣服和头发的延迟、液体的流向都要与动作一致。复杂动作不要把靠近、蓄力、撞击、反应和新动作全塞进一个时间段；先让关键动作处于可读阶段，必要时拆镜头。

对白只放在声音区：说话人的声音特征、准确台词、发声时机和混音。动作区可以写“听到声音后停手”，不要在其中重复台词。没有台词的人保持静默；上一镜头的尾句若只用于节奏衔接，明确标注为音频上下文，不让模型把上一镜头的人或物带进画面。是否禁用配乐由项目决定，不能把案例项目的“只用环境声”当作普遍规则。

## 正面约束与失败锁

先写希望画面呈现的状态，再在附近补一个短的失败锁，例如“人物背对较亮背景，脸保持在阴影里；没有平面正面补光”。只在已有失败反复出现时增加“无重复人物”“无空首帧”“无错误视线”等局部限制；不要堆一长串泛化否定词，让真正重要的信息被淹没。

## 原创小例子：双镜头的衔接

任务：两个 6 秒镜头，成年修表师在工作间发现旧表异常。无对白，写实；仅编写分镜，尚未生成。

固定场景：木工作台靠北墙，台灯位于工作台西端，入口在南墙；摄影机始终在工作台南侧。角色为 C01-dry-v1，旧表为 P01-closed-v1。

镜头 A：从南侧看中景，台灯在画面左侧。修表师坐在台后，旧表放在桌面，右手持镊子。0–2 秒用镊子靠近表冠；2–4 秒滴答声意外停止，镊子悬停；4–6 秒视线从表移向画面左侧的灯，身体留在原位。出点明确：表仍合盖、镊子仍在右手。

镜头 B：同侧切面部近景，开场承接看向画面左侧的视线。0–2 秒眼神移回桌面；2–4 秒吞咽并缓慢呼气；4–6 秒低头，将注意力重新放在旧表上。桌外的手和道具不另行改写成已交接或已开盖。声音延续同一房间底噪。

这只是分镜示例；正式提交需附真实参考图并展开角色、道具的已确认描述，不能把 C01 或 P01 当作模型自动认识的人物。

## 迭代与后期

每次记录：镜头 ID、版本、输入全文、模型与参数、参考资产版本、任务或结果标识、观察到的缺陷、修改项、结果与下一步。可用表格或项目现有记录方式，不强制新建数据库。

优先排查：输入矛盾 → 引用或状态错误 → 站位与时序不清 → 动作过载 → 模型能力不足。一次验证一个主要原因。若结果长期不改善或接近预算上限，改镜头设计，不继续无上限润色提示词。

粗剪检查场景是否讲得通，再补必要反应镜头、插入镜头或空间交代。逐段检查脸、手、文字、闪烁和物理接触；首尾不稳定帧按实际情况裁剪。统一镜头间光色，清理对白，衔接环境声与音乐，最后核对实际输出规格。只有实际看过或听过的项目才标记为检查通过。
