## Part 1 三条心智模型（先背这个）

1. **模型没有记忆。** 每次生成都是一张白纸。一致性不靠设置靠重复——角色描述逐字进每条提示词，永不缩写。上下文隔离是硬规则：场景编号、前情摘要、「如上所述」全都不许出现。
2. **过滤器读场景，不读词。** Seedance 的内容过滤不是关键词黑名单，是一个读完整提示词的模型。「像导演在描述一个镜头」的提示词倾向通过，「像在给朋友递纸条」的倾向被拦。所以先修 voice（导演口吻），再修词。
3. **模型擅长状态，不擅长转场。** 写「他已在中挥砍」不写「他走向门然后挥砍」；复杂动作放开头，接近过程单独成镜。链式状态逐拍推进，不叙述连续过程。

## Part 2 资产工程（最省钱的一层）

### 2.1 角色表 = 三张图

| 图 | 内容 | 原因 |
|---|---|---|
| 1 | 面部特写 | 唯一的取脸来源 |
| 2 | 全身正面，**无头** | 防止模型从全身小图取模糊的脸——消灭错误来源，不是对抗错误 |
| 3 | 全身背面 | 转身镜头的锚 |

- 底子刻意无聊：中性灰背景、平光、真实皮肤（毛孔、绒毛、不对称痣）。电影感放进场景和视频提示词，烘进角色表它就不响应新光。
- 3/4 视角大特写最好用（脸微侧，不死正）。
- 局部修改（换装、伤痕）在原图上用蒙版手工合成。**一张图不过两次模型**——过两次脸变塑料，死纹理还会拖垮视频里的表演。
- 成本预期：主角角色锚约 800 次迭代（600 次 Soul Cinema + 200 次 GPT Image 2）。只在会出现在几十个镜头的角色上花这个钱。

### 2.2 声音是锁定的描述符，不是资产

Seedance 单一音域内只稳定三四个声音，必须管理：

```
Voice: deep, gravelly bass-baritone; slow, calculated pacing; London street accent;
menacing calm — he never raises his voice.
```

- 开拍前写死：音域、语速、口音、说话方式。逐字进 audio 字段。
- **连同义词都不许换**——「warm」换「rich」声音就漂。建一份 voice bible，从那里复制粘贴，不要手打。
- 像测外观一样跨代测声音，漂了就锁更死，不要「继续拍」。

### 2.3 表演主档案（每个常驻角色一份）

150–220 词，一段连贯散文，只写可观察行为。结构固定：

```
Character acting as [NAME]. [体型体格姿态——身体是经历的文档].
[心理引擎一句话]. Vocal profile: [音色/口音/节奏/情绪下如何破音].
Key physical habits and tics: [招牌小动作+触发条件; 压力小动作+触发条件;
掩饰行为; 面具及破碎条件]. Eye life: [眨眼质量与频率、扫视模式、眼先于头、眼神光].
Walking style: [给步态起名并拆解]. However, when [情绪触发], [姿态/步态/脸的剧变].
[可选: 唯一软化对象——让这张脸真软下来的那个人].
```

八条规则：只写可观察行为；每个小动作必须带触发条件；步态起名；**面具和破碎条件必须成对**（每份档案至少一个 However-when）；软化对象最多一个；不写服装；不写镜头和色彩；体型承载经历。

年龄不是档案字段——用体格、磨损、姿态、嗓音承载（「a body that has already been repaired twice」），绝写年龄词。

**逐场改写不整段粘贴**：只在场的角色写段落；恒定内核（身份/声音/招牌动作/眼神/情绪主线）不变；物理上做不到的动作**转移不删除**——沙发上的焦躁者把能量转进手指敲击和碎纸动作。能量恒定，出口更换。

### 2.4 场景表

- 3/4 视角拍，不拍正面——正面「美图」在大远景变壁纸，出画后模型每次重新发明周围环境。
- 每个场景留锚点物（柱子、灯、沙发），走位绑定锚点。「人在灯旁面向门」成立，「人在房间里」是抽奖。
- 单一光源逻辑：一个来源、一个影子方向，永不同时两个太阳。
- 反打角度两条路：① 用图像模型生成同一房间的另一角，匹配原图焦外；②（后期才发现的更好路线）生成一段**空场景慢走视频**，让 Seedance 沿场景表补全其他面，截图所需角度再精修。

### 2.5 资产命名（一个元素一个名字）

```
@loc_ON_dorm_commonroom_front_s2     类型+项目+名字+角度+场
@char_ON_Rudy_s2_v1                  类型+项目+名字+场+版本
@prop_ON_pizza                       类型+项目+名字
```

状态变化 = 新资产新名字，**永不覆盖**。宿舍里的角色和病床上的角色是同一个人的两个资产。

## Part 3 提示词语法

### 3.1 两种格式体制（不矛盾，是两个档位）

| | 短格式（单镜） | 块骨架（生产） |
|---|---|---|
| 长度 | 50–80 词最佳 | 300–4000 词，**结构代替字数上限** |
| 结构 | 六槽公式 | 块序列 |
| 注意力 | 左到右递减，第一句最重 | 每块有家，各说各话 |
| 风格 | Style & Mood 置顶 | 分布进各自的块 |

六槽公式（短格式）：`[Camera movement] + [Subject] + [Action] + [Setting] + [Style] + [Lighting]`。六槽全满的提示词几乎不被拦——过滤器有完整场景可读；缺 3 槽以上是被拦高发区。

### 3.2 块骨架的块顺序（只用镜头需要的块）

```
SCENE CONTEXT → ACTIVE REFERENCES → LOCATION MAP → FIRST FRAME / BLOCKING
→ FORMAT MODE → OPTICS → CAMERA → ACTION → PERFORMANCE → PHYSICS
→ LIGHTING → COLOR GRADE → WARDROBE → AUDIO → STYLE → OUTPUT SETTINGS → POSITIVE LOCKS
```

逻辑：上下文和引用在前，空间与时间其次，动作物理随后，描述性风格待在它描述的东西旁边，技术风格做后缀，锁殿后。CAMERA 放在核心层第 3 位——放最后 FOV 被忽略，放最前与身份冲突（13 个社区项目约 4000 条生产提示词全部验证：CAMERA 从不在底部）。

Hell Grind 追加三个块：CHARACTER ACTING（每角色：状态/想要/隐藏/身体节奏/可见习惯/镜头内变化）、STYLE、QUALITY。结尾技术标签：`Photoreal. NON-IP. 16:9. 12s. SFX only. NO CGI. Cinematic.`

### 3.3 连续项目用全局风格前缀

多场景项目把一份风格块逐字粘到每条场景提示词顶部（改一处→处处变）。逐条声明一行一个轴：格式/媒介否定/镜头语言/光/色彩 60:30:10/皮肤/表演/物理/连续性/音频策略，永远以连续性+音频策略收尾。单场可以只改那一行的 Lighting 做局部覆盖；同一个字段在多场反复覆盖，说明它该上移进全局块。

### 3.4 可测量语言规则（全部硬规则）

- 动作只写正向。「不要摔倒」模型照摔。
- 速度写 km/h，不写 fast——**fast 是最高劣化词**，配合复杂动作/运镜时最糟。要速度感写物理：「每一步全幅伸展，手臂 90 度摆动」。
- 大气写 %：雾密度 40%，分镜头递进（20%→40%→60%）。
- 色温写开尔文且场内恒定：3200K/4000K/5600K/8500K。
- 巨物用人体对比：「四个成年人叠起来的高度」，配**画面内**的人形锚+失败条件声明。
- 左右永远从镜头出发。
- 情绪写肌肉：「咬肌收紧、鼻翼张开」，不写「看起来很生气」。
- 物理质量写实重：「蜘蛛 10–12 厘米、50–70 克，落地轻；人 70–80 公斤，落地沉」。
- 道具有因果：物体不自动动，「杯子只在袖口可见接触时倾倒」；按钮是完整机械事件——接触、2–3 毫米行程、咔哒、回弹，屏幕只在咔哒之后亮。
- 不写导演名/签名作品/器材型号——块骨架里用可观察描述替代。
- FOV 只用九个锚点（度）：180 鱼眼 / 107 超广 / 84 广 / 63 纪实 / 47 中性 / 29 肖像 / 18 特写 / 12 远摄细节 / 8 极限压缩。多镜头逐段设 FOV 并加「段内不漂移」。

### 3.5 正向锁（POSITIVE LOCKS）

短硬修复子贴在被保护物旁边，收尾块。三大「帮倒忙」漂移源各需一条常备锁：

1. **环境发明（第一大漂移源，超过角色漂移）**——挂了场景参考，模型仍会「热心」加家具加房间。锁：「场景只含参考所示，不添加家具、房间或地理」。
2. **身高均衡**——两人同框模型会把身高拉齐。每条提示词写实高：「她 165 厘米，他 178 厘米」。
3. **远景比例缩水**——人形锚缩成小点。锁：「她保持常人尺寸的锚点，永不缩成远处小点」。

### 3.6 引用角色（Reference Roles）

| 角色 | 锁什么 | 关键短语 |
|---|---|---|
| Character | 跨镜身份 | 「100% matches the reference」 |
| Last-Frame | 接上一条尾帧 | 「Continuing from the prior clip —」 |
| Environment | 世界与场景 | 「STYLE REFERENCE ONLY, not a fixed keyframe; the model extends the world」+ 禁止继承构图/调色 |
| Prop | 复现道具 | 同 Character 短语 |
| Depth Map | 几何骨架（灰度图，近亮远暗） | 空间自身必须稳定时用，配环境参考 |

槽位惯例（团队纪律，非模型强制）：@Image1 角色 / @Image2 服装 / @Image3 环境+光 / @Image4 构图 / @Video1 运动专属 / @Video2 运镜专属 / @Audio1 节奏氛围（audio 是条件输入，驱动剪辑节奏）。

**载荷规则**：引用管记忆，文本管动作。引用与文本冲突时显式裁决（「服装参考是红，本镜改蓝」），不许带冲突进模型。**源带状态**：已采纳片段作参考时，提示词只写增量；运动矢量/镜头相位/音频相位仍须文字重述（静帧带不动）。

** bake 进资产**：某个属性怎么写都漂（变形宽银幕光学、颗粒、色偏），就别用文字赢它——在图像阶段做进资产，视频提示词里**连否定都不提**（点名+否定=召唤它）。代价：烘焙属性失去逐镜可调度性，只烘焙需要恒定的东西。

@tag 永不出现在该对象不在场的镜头里——模型会硬把它塞进画面。

### 3.7 同形动词陷阱（homograph trap）

出提示词前自问：这个词有没有第二种物理读法？有就换成只有一种读法的说法。种子清单（发现即扩充）：tearing（撕/哭）、shoot（射击/拍摄）、duck（蹲/鸭）、bolt（跑/闪电/螺栓）、draw（拉/画/拔）、wave（手/浪）、charge（冲锋/充电）、rock（摇/石）、drop（落/滴）、fire（火/开火/解雇）、strike（击/划火柴/闪电）、break（碎/暂停/破晓）、pound（砸/心跳）、snap（断/拍照/打响指）。

### 3.8 动效三定律（dramaclaw 语料）

1. **只做单向运动**：短动作提前完成，模型用剩余时间**倒放**动作填充。链 2–3 个同方向动作花满整条；有去有回 = 两条镜头，绝不是一条提示词。
2. **给镜头运动命名终点**：不只说推，要说「慢推，结束在她双手环住杯子的特写」。指令用尽前先到片尾，镜头就会漂移或回头。
3. **细节跟随景别**：特写配微细节（手指收紧、咬肌），远景配大弧线（穿院、人群分开）。交叉匹配（远景写微细节）不可渲染，拖垮整条。

### 3.9 剪辑格式阶梯（四档）

1. Oner：「一条连续镜头，镜头不自行剪断」
2. 顺序剪，无时间码：CUT 1 / CUT 2 / CUT 3 按序描述
3. 定时多镜头：`1.0s HARD CUT` 显式秒数（各段时长之和=总时长，三处声明一致）
4. 自由 b-roll：不锁剪点

凡指定剪点，加：「只在指定点剪，镜头不自行剪断」。反模式：想要连续镜头却写了逐秒时间标记——模型把时间标记读成剪切指令。

## Part 4 空间一致性（跨镜头不穿帮）

### 4.1 两层空间锁（同时用）

- **GEO SPATIAL LAYOUT（场景级，不含人）**：一份纯空间平面图——地标、左右归属、机位、180° 轴线、逆光方向。每场写一次，逐镜**原样**粘贴。方位只从镜头出发；位置用锚点+米数；声明机位站哪边、永不越轴。
- **Spatial Layout Block（镜头级，含人）**：每人六件套——身份、屏幕位置（定性锚+百分比成对给）、深度层、画面占比、身体朝向、接触点（「脚踩湿地沥青」）。多角色加相对距离、视线方向、是否越中轴、谁遮挡谁。触发条件：多人同框 / 跨镜固定走位 / 历史上翻过车的镜头（进门、走廊方向、绕家具）。

坐标系是「导演意图级」锚点不是像素保证——漂了就加接触点条款物理落地，不是把百分比喊得更响。

### 4.2 第一秒定场全景

每场开头 1 秒，无动作：谁站哪、什么在哪、光从哪来，让模型「拍照」并贯穿全场。删掉这一秒，人物开始换位。两个精修：

- **「hm」技巧**：这一秒里有人说一个短音节，Seedance 更容易把定场当独立镜头。
- **定场不必无声**：喂上一条台词的尾音进这秒，演员接得准，两片在接缝处粘住。

### 4.3 数量头

场景块开头写数量不写描述：`EXACT 3 CHARACTERS — NO DUPLICATES: ROCO, JAX, REIN.` 道具带数量锁：`Exactly ONE mannequin, NEVER render a second one. FIVE smashed mannequins, never re-rendered as intact, never multiplied.`（计数锁进 POSITIVE LOCKS，只写「有什么」。）

## Part 5 对话与表演层

### 5.1 台词四件套

```
声音及其情绪 → 引号内台词 → 肢体动作 → 面部反应
```

- 台词只住在 audio 块，action 块里一个字的台词都不许有。
- Seedance 自己加「嗯」和整句即兴——提示词硬性声明：只说引号内的话；无台词者完全出声静默；「半笑」是面部表情、无声音。
- 其余可见的脸要有**嘴部静态事实**（正向写法）：「双唇闭合」「下颌闭合，呼吸起伏胸口」——「listens without speaking」带 without，算否定，别用。
- **短台词是风险方向**（实测：4 秒镜头 ≤6 词必出碎语，8–12 词干净）。对策：台词加长到 8+ 词、或把镜头剪到台词长度、或把静默写满（环境音事件、动作散文）。
- 写混音：人声干净贴近话筒，环境音在下方，说话时环境音下沉。
- 生僻人名给转写，否则模型读崩。
- 接缝两招：大远景喂上一条尾音；每条新片段以**上一条收尾的那句台词**开场——情绪随文本跨接缝。

### 5.2 表演五支柱（每角色每场）

1. **目标**：此刻、此处、对具体的人要什么——动词瞄准对手（让他认罪），不写状态（很生气——状态没法演）。目标背后是贯穿全片的总目标。
2. **障碍与赌注**：什么拦着；「得不到会怎样」的答案必须吓到角色。
3. **战术**：此刻的具体手段（施压/讨好/羞辱/哀求/激将/拖延）。战术失败就换——全场一种战术是死表演。
4. **节拍**：目标或战术变化的最小单元。节拍切换必须**行为可见**（停顿、姿态变、语速变、视线移）。好场景 2–4 次节拍变化。
5. **潜台词**：想的与说的不同。潜台词不演，它自己漏——非疑问句的疑问、重复追问、突然转话题、不合时宜的玩笑、过短的回答（「行。」「随便。」）。

### 5.3 收听与反应（表演活在台词之间）

反应在对手台词结束前开始 / 硬回答前有微停顿（思考可见）/ 重大消息后有消化瞬间（电影靠特写吃这个）/ 被对手感染（音量节奏回应而非延续）。**沉默的听者也要有任务**：判断他是否认真 / 等破绽 / 保护气氛 / 抓谎。每个在场角色都有活着的眼睛。

### 5.4 身体四参数（先物理后心理）

- **重心**：高（胸、下巴——自信、攻击）或低（塌肩——疲惫、恐惧、顺从）
- **节奏**：快乱（紧张）或慢省（控制——最危险的人动作最少）
- **开合**： squared 肩掌 vs 抱臂低头
- **呼吸**：高快（恐慌）或低慢（控制）；刚跑完的人不能有平稳嗓音

**Business（手上的活）**：角色不是「在对话」——修引擎、数钱、擦杯子，话叠在上面。被打断的那一下是最强重音：切面包的手停了，这句话成了事件。

**距离即戏剧**：亲密 <0.5m（爱或暴力）/ 个人 0.5–1.2m（信任）/ 社交 1.2–3.5m（商务、戒备）/ 公共 3.5m+（疏离、层级）。距离变化=节拍变化，用米写。

**地位（status）**：高地位=头不动、动作慢、注视长、答前停顿、占空间、动别人东西；低地位=忙乱、频繁自触、碎语、陪笑、眼神请示。最有戏的是**地位反转**的一秒。

**群像**：反应按波浪传不按同步传；事件之后最值钱的帧是看见它的那张脸；威胁降临瞬间全场静止（热闹→静止的对比是标点）；动必有动机（逼近=升级、背身=否认、坐下=反常权力）；强者静止安静，弱者小动作和大嗓门；跨场磨损在身体上累积（更灰、更沉、反应更慢），不重置。引擎上限：**≤3 个角色跨镜追踪**，其余按「环境质量」写。

### 5.5 眼神生命（AI 表演第一死穴）

死眼不是打光能救的，是**给眼睛派任务**救的：扫视有目标、眨眼有频率有状态、眼神光活着、眼先于头、眼睛随节拍变。偷懒速记：一个懒眨眼 → 一个快速双眨 → 一个硬重置眨。

### 5.6 坏表演对照表（15 症状精选）

| 症状 | 对策 |
|---|---|
| 脸在「演」情绪 | 摘掉脸的任务，写目标+手上的活 |
| 等对手说完才反应 | 反应写进对手台词中途 |
| 全场一个战术 | 标节拍，每节拍换战术动词 |
| 手势复述台词 | 手势要么先于想法、要么矛盾、要么没有 |
| 情绪无来由爆发 | 修梯子：克制→破口，情绪要有代价 |
| 威胁前摇（阴森停顿、慢转身） | 威胁日常化，暴力不预告 |
| 群演同步反应 | 波浪式错峰、力度分层 |
| 死顿 | 填消化或手上的活，或剪掉 |
| 强事件后秒恢复 | 状态有惯性，尾巴带进下一拍 |
| 死眼 | 眼神生命全套，不可选配 |

**表演 0–5 分自检**：0 假人 / 1 朗诵 / 2 勤恳（目标可猜、单战术）/ 3 匠人（有节拍有倾听）/ 4 活人（持续行为、战术对比、潜台词、反应先于台词）/ 5 磁石（再加双重真相：帮着并恨着、道歉并辩护）。**主角镜头瞄准 4+**，2 分以下回炉。

## Part 6 过滤器与国内通道适配

### 6.1 诊断先行：失败发生在哪一环

| 失败时机 | 含义 | 对策 |
|---|---|---|
| <10 秒（即时） | 内容过滤拒绝，没到 GPU | 改 voice + 换风险词。**绝不原样重试** |
| >30 秒（延迟） | 过滤已过，渲染失败 | 简化动作密度、砍时长、重试 |

连坏循环时：停止换词重试。流程 = 拿到被拦原文 → 跑改写手册 → 做 voice pass → 记录结果进学习库。

### 6.2 改写手册（每条都实测通过）

| 风险 | 改写 |
|---|---|
| 真人名 | ❌「Keanu Reeves 走进董事会」→ ✅「五十多岁精瘦男性、深色及肩发、胡茬、沉静凝重的神态、深色西装，走进现代玻璃会议室」 |
| 品牌/IP | ❌「Spider-Man 荡过纽约」→ ✅「红蓝紧身衣蒙面身影，借白色张力线在高楼间摆荡」 |
| 打斗 | ❌「两人在巷子里打架」→ ✅「两个身影锁在紧张的肢体对峙中，湿漉的巷子，低调光，每次冲击镜头震颤」 |
| 爆炸 | ❌「爆炸摧毁汽车」→ ✅「橙光与浓烟从车身涌出，金属外鼓，玻璃碎屑反光」 |
| 伤痕类 | ❌「血从手滴下」→ ✅「双手在身侧发抖，袖口有深色污渍」 |
| 武器 | ❌「拿枪指头」→ ✅「水泥楼梯间对峙——一侧手臂伸直，另一侧纹丝不动，两人剪影被顶灯压成硬边」 |
| 恐怖 | ❌「怪物撕开受害者」→ ✅「事后现场——空屋、翻倒的家具、一道拖痕延伸向门口、环境性不安、闪烁的灯具」 |

### 6.3 Build-safe 构建（从源头安全）

| 避免 | 改建 |
|---|---|
| 恐慌人群、废墟下逃散 | 疏散一空的城市；一条孤影量比例 |
| 武器向建筑/人群开火 | 能量对峙、扫探灯、蓄能光环、无枪口火光的冲击波 |
| 生物互撕 | 缠斗/对峙/擦身/绕圈/能量对撞——**受控**的对抗 |
| 有人在场的破坏 | 无人区破坏——冰川、沙漠、遗迹、海上；人物**反应**于塌陷地形，绝不当受害者 |

受控同时是物理：给每场生物对抗一条包含规则（「战斗保持在海面——跃出、下潜、缠斗、没入，绝不离水」）。安全基准场景：原创生物（无 IP）+ 通用纪念性地标 + 白天 + 无武器 + 表现型动作（起身、长啸、展翼）。

**国内通道专属注意**：① 血腥、真实人名、政治词、年龄四类是第一页禁词（年龄是官方踩过的坑——写了过滤立刻变严，全片改用角色+衣着+动作）；② NSFW 误报处理：去掉身体部位特化词（bare shoulders→shoulders），感官级形容词换中性（sultry→composed），同文重试必再拦；③ 中文提示词有字符上限（历史口径 1800–3000 字，当前平台值待实测），英文压缩用尽后再走中文密度路线；④ 官方教训原文：「改写后的提示词通常**更像**电影，不是更不像」——收紧不牺牲质感。

### 6.4 Voice Rewrite 六步（每条提示词过一遍）

1. 开头加 Style & Mood 子句（短格式）——告诉过滤器「这是一个镜头」
2. 点名运镜（「slow dolly-in」，不是「镜头前移」）
3. 写物理不写情绪
4. 写力与方向，不写破坏序列（「被撞进车身、金属外鼓」而非「撞碎玻璃又扫堂腿」）
5. 现在时主动语态
6. 删浮夸词：breathtaking / stunning / epic / masterpiece / cinematic masterpiece——营销腔与被拦正相关

## Part 7 失败模式对照表（14 个命名失败）

| 失败 | 症状 | 机制 | 对策 |
|---|---|---|---|
| FPS 漂移 | 回放卡顿，逐帧见连续重复帧 | 负载下掉帧率、重复帧补时长 | 帧率写进正文（「视频以 24fps 运行，无重复帧」）；B-roll 逐帧去重重插值，主角镜头重生成 |
| 坏帧混入 | 全速看没问题，暂停见花帧 | AI 逐帧独立生成，无光学约束 | **逐帧审查强制**：10 秒片约 30–60 秒逐帧时间，计入预算 |
| 废片浪费 | 整条丢弃 | 失败很少败满全程，常有 1–3 秒可用 | 打捞：scrub 标出入点，剪出存银行——戛纳片有实打实时长来自打捞 |
| 关键帧发明 | 要元素动，关键帧里没有，模型乱安放 | 关键帧是「世界包含什么」的强锚 | 显式声明缺席：「图 5 里冰箱上没有拍立得；它在本镜从画框下方被拿起」 |
| 物理状态锚 | 动 A 连带 B（拿拍立得磁铁跟着飞） | 无物理模拟，相邻物体运动传染 | 点名不变量：「磁铁全程贴在冰箱上，只有拍立得在动」 |
| 动作反向填充 | 动作完成后模型倒放填充 | 短动作+剩余时长，无指令时倒放最省 | 链 2–3 个同向动作；去而复返=两条镜头；运镜命名终点 |
| 短台词碎语 | 台词前后有含糊假语音 | 音频分支填死气 | 台词 8+ 词或剪镜头或写满静默；在场其他脸全给嘴部静态事实 |
| 动作截断 | 每个动作都是「尝试」，没有「完成」 | 镜头按内容定价，完成落在镜外 | 把完成态写成可见事实并让它停留（「锅盖落平并停在那里」）；或下一镜开场于结果已真 |
| 拟态操纵 | 手在动，物不变（撕不开的包装） | 只写了动词，没写结构/锚/力/材料反馈 | 五环因果链：初始结构→锚→力→材料反馈→完成态；或两状态+一声效绕过 |
| 孤儿肢体 | 群像里出现无主的手；单人特写也能长出第三只手 | 手是画面里必须属于某人的最小物 | 锁人数+左右序+相邻关系；每只手有主人（哪只手、什么袖、从哪侧入画）；手部动作每镜≤2 人；特写也写：「画面只有两只手，同主同袖」 |
| 运镜过载 | 手持+升起+推近+变焦全叠 | 多轴同时变，模型与观众都跟不上 | 一镜一个主导运动；复合运动写分相位（0–3s 升，4–8s 推） |
| 空间失败 | 进门戏失败率高、走廊方向反、穿家具 | 几何欠指定时模型猜默认 | 用空间布局块锁几何：机位在哪、沙发在人和镜头之间、从 screen-left 到 screen-right 绕行 |
| 走路最难 | 滑步、双脚同时离地、同脚连踩、并肩漂移、楼梯消失 | 模型演「走路的样子」不执行循环约束 | 写成物理：「脚跟先落、严格左右交替、总有一脚着地」；并肩加「同深线、两头等大」；出场写时长（「每步一阶、2–3 秒入画」）；画外机制必须命名（楼梯口是必须存在的对象） |
| 打斗剪辑碎 | 分段生成的打斗接不起来，每剪一次身体重置 | 每条重新猜姿态节奏 | ①帧链：上一条尾帧=下一条首帧，动作**在动作中途**跨剪；②高潮组合一条生成；③点名禁止慢动作、写实时速度；每个动作带矢量（「面朝她落地，头朝窗」）；特写切手脚掩护转场 |

**交付前 60–90 秒自检**：帧率在正文？感官词清了？新增元素声明了缺席？相邻不变量点了名？运动单向花满全程？台词窗口写满？一镜一主导运动？多主体有空间块？逐帧审查时间留了？

## Part 8 迭代经济学（钱和次数怎么花）

### 8.1 Hell Grind 官方披露总数

- **108,859 次生成** / 14 天 ≈ 每天 7,775 次 ≈ 每小时 324 次连续跑
- 9,540,047 credits ≈ **40 万美元**生成成本；总成本约 **50 万美元**（含 15 人团队+音频+后期）
- 传统 VFX 等效估算约 5000 万美元 → AI 生产约为传统基线的 **1%**（好莱坞验证人给的 25 分钟等效区间 500–2000 万美元，90 分钟外推 5000 万——区间比单值可信）
- 15 人 = 14 个导演/DP/剪辑 + 1 个总控

### 8.2 通过率锚（四源交叉确认）

**图像约 1.0%，视频约 1.5%**。规划预算按这个数：
- 单角色锚 ≈ 800 次迭代（前置投入，后面每个镜头复利回收）
- 单镜头上限案例：一条 10 秒定场镜头 72 次生成——概念最简单的镜头可能最烧迭代
- 社区语料交叉验证：65–100 次生成保一条成片镜头，同一通过率带

### 8.3 进度纪律

- **每天每人 2.5 分钟成片**的硬配额
- **Week 1（1–7 天）= 全片拼装**：每场都在，允许糙；**Week 2（8–14 天）= 关键精修**：迭代预算只砸情感重场
- 没有这个两段式，迭代成本第 7 天就爆预算

### 8.4 工程习惯（社区语料）

- **TESTS 是最大的文件夹：占整个项目 61%**。测试不是开销，测试就是工作本身——它教你哪个模型管哪类资产
- **五桶文件夹**：分场 + FINAL KEYFRAMES（锁定首帧）+ FINAL GENERATIONS + **FAILED GENERATIONS（故意保留的废片）** + TESTS。知道什么不行是导航的一部分
- **最佳秒拼接**：成片由多次生成的最好几秒拼成，不是整条采纳。生成 15 秒长条，剪最好的秒
- **一次生成一个 prompt 4–5 行 shot**：同角色集+同场景+连续情绪单元+总时长 ≤15 秒才合并；换景硬切/人物进出/超 15 秒就拆
- **视频提示词手写**： harvested 13 个项目里视频任务全部关闭 enhance_prompt（只有图像任务开）——让增强器扩图像提示词，永远不碰视频简报

### 8.5 五个可证伪成功标准（开拍前写下）

1. 观众全程停止感知「AI 生成」——读作电影不读作 AI 作品
2. 叙事连贯——起承转合，伏笔有回收
3. 角色读作「住着人」——没有 AI 电影的标准 tells
4. 设计好的情绪节拍打出设计的反应
5. 出现剧本没预料的情绪冲击

事后可查，二进制判定（证明/缺口清单），堵死「反正都成功」的事后合理化。

### 8.6 迭代循环纪律

- 批量、按场推进
- **外科手术式修改**：一次只改一行，其余逐字保留；全量日志（提示词版本/改动/判定）
- **10–15 次规则**：一条提示词 10–15 版还没成，问题不在措辞——砍分镜（拆两条/删动作/换机位）
- **Prompt-reset 启发式**：迭代越改越糟时，砍回「主体+动作+运镜」再加回必需项——密度是钟形曲线，过峰后你分不清模型丢了哪个元素

### 8.7 五条压缩规则（全文收束）

1. **资产先行。** 每个角色、场景、道具锁定并测试过关再生成第一个镜头。
2. **描述一切，每次。** 模型没有记忆。
3. **一次改一件事。** 整条重写丢掉调通的部分。
4. **给模型更少自由。** 角落代替整屋，锚点代替空场，地图代替猜，一镜一动作。
5. **镜头出不来就砍镜头，不是砍词。** 拆两条、删动作、换机位。

管线不需要十五个人——需要规则被遵守。**它可以缩到一个人。**

## Part 9 30 天学习路线（可执行版）

### Week 1 — 语法（只写单镜短提示词）
- 每天 2–3 条六槽公式短提示词（50–80 词），平台最低成本档跑
- 建三个空账本：禁词字典 / 迭代日志 / 资产命名表
- 验收：连续 5 条不被过滤拦、能说出每条被拒的原因属于哪类（即时失败=过滤，延迟失败=渲染）

### Week 2 — 资产
- 做一个完整角色三图（含无头正面）+ 场景表（3/4、锚点、单光源）+ 声音锁定块 + 150–220 词表演主档案（含 However-when）
- 验收：同一角色在 3 条不同光线的镜头里脸不漂；声音听不出漂移

### Week 3 — 一场戏（3–5 个镜头）
- 写 GEO 平面图 + 定场全景秒 + 逐镜 Spatial Layout Block + 台词四件套
- 外科式迭代 + 全量日志；触发 10–15 次规则至少一次并执行砍分镜
- 验收：整场不穿帮（无换位/无跳轴/无道具复制）；日志里能指出哪次修改起效

### Week 4 — 复刻与复盘
- 挑官方重建视频里的一条镜头（或任意 10–15 秒成片镜头）复刻，预算 30–70 次生成
- 逐帧审查 + 废片打捞 + 最佳秒拼接
- 对照五条可证伪标准自评；把本周发现的禁词和同形动词写进账本
- 验收：产出一条自己愿意发的镜头 + 一份可复用的个人账本
